# 深渊酒馆

简体中文 | [English](README.en.md)

**AI 跑团 × 挂机探险 × 角色养成**

在酒馆里为下一次出发做好准备，再看看你的冒险者，会把怎样的故事带回来。

《深渊酒馆》是一款 AI 驱动的奇幻文字 RPG。创建自己的冒险者，搭配装备与技能，和同伴一起探索地下城。AI 会结合队伍的能力、性格、经历和当前环境，演绎战斗、奇遇与冒险故事。

每次归来，都可能带回新的装备、技能和特质，也可能留下伤势与损失。角色的成长和经历会持续保存，成为下一次冒险的起点。

游戏经过数百名玩家参与、持续数月的测试与优化，不断打磨剧情体验、角色成长与酒馆玩法。

## 有什么可玩？

- **组队探险**：组织队伍、准备物资、选择目标，出发后自动推进探险，回来阅读属于这支队伍的故事。
- **角色养成**：培养职业、学习技能、积累特质，围绕装备与能力的组合，形成自己的冒险风格。
- **地下城与奇遇**：探索不同地下城，遭遇特殊事件，发现隐藏副本，挑战危险的敌人。
- **特殊机缘**：前往转职试炼场寻找职业成长的机会，在顿悟秘境领悟技能，到祛厄药庐寻求治疗。
- **酒馆建筑**：向导师学习，在构装工坊组合材料，在灶坊尝试料理，也可以休息、治疗，为下一场冒险做准备。
- **物品与交易**：收集战利品、整理仓库、搭配随身物品，在市场中寻找需要的装备与材料。
- **委托与互动**：完成委托，参与酒馆中的互动，阅读其他冒险者的探险记录，在日志下交流见闻。

游戏以出发前的准备和归来后的养成为主要节奏。你可以琢磨能力搭配、追求角色成长，也可以慢慢读故事，看着自己的冒险者积累一段段经历。探险有收获，也有受伤、损失乃至死亡的风险。

## 开一间自己的酒馆

你可以自行部署，独自游玩，或邀请朋友一起冒险。平台支持创建多个独立酒馆，各自保存角色、物品与世界记录。

游戏仍在持续完善，欢迎分享游玩体验、提交问题和参与改进。

## 模型建议

**中文剧情正文生成唯一推荐使用 `deepseek-v4-pro-0423`。** 根据本项目的实际测试经验，后续新版本在中文剧情正文上的效果较差，建议固定使用该版本，不要自动替换为最新版。

## 开始游玩

安装 Python 3.12+ 和 Node.js 22.12+ 或 24 LTS，下载并解压源码后：

- **Windows**：双击 `tools/setup.cmd`，按提示填写模型接口地址、API Key 和模型名，再创建管理员。
- **Linux / 终端**：在项目目录运行 `python3 tools/setup.py`。
- 安装完成会启动游戏，浏览器打开 `http://127.0.0.1:5500`。以后 Windows 双击 `tools/start.cmd`，Linux 运行 `python3 tools/start.py`。

完整的 [安装与模型配置教程](docs/DEPLOYMENT.md) 包含 Key 怎么填、模型怎么换、如何邀请朋友，以及服务器部署说明。玩法与默认设置见 [游玩指南](game-packs/s1-fantasy/SELF_HOSTED_RULES.md)。

第一次开服请看 [管理员入门](docs/ADMIN.md)：开放酒馆、让玩家入驻、调整 AI 与运行节奏，以及常用管理入口。

以后更新游戏：停止服务后，Windows 双击 `tools/update.cmd`，Linux 运行 `python3 tools/update.py`。工具先备份，再更新程序，保留配置与玩家数据。详见 [更新游戏](docs/DEPLOYMENT.md#更新游戏)。
