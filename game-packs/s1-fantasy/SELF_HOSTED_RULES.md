# 深渊酒馆游玩指南

简体中文 | [English](PLAYING.en.md)

创建自己的冒险者，在酒馆中准备装备、技能与物资，独自出发或和同伴一起探索地下城。探险自动推进，归来后可以阅读故事、整理战利品，再决定下一次冒险的方向。

## 探险与成长

- **自由组队**：普通探险支持单人出发，也可以与其他冒险者组队。
- **持续养成**：装备、技能、特质与冒险经历共同塑造角色，已获得的成长和物品会持续保存。
- **能力组合**：技能、特质与物品按各自描述发挥作用，包括对应的触发条件、代价和状态。
- **风险与收获**：探险可能带来战利品和成长，也可能造成受伤、损失或死亡。出发前的准备会影响冒险过程。

## 酒馆生活

在酒馆中休息与治疗，向导师学习，尝试构装和料理，参与委托、交易与互动。你也可以阅读队伍的探险日志，在评论中交流见闻。

特殊场所提供不同的成长机会，例如转职试炼、技能顿悟与治疗。具体参与条件和效果以游戏内说明为准。

## 默认容量与数值

| 项目 | 默认上限 |
| --- | --- |
| 永久属性 | 200 |
| 生命上限 | 1000 |
| 随身物品 | 5 |
| 携带技能 | 5 |
| 仓库容量 | 100 |

学会的技能与当前携带的技能分别管理，可以根据探险目标调整搭配。

## 自己开一间酒馆

平台支持创建多个独立酒馆，各自保存角色、物品和世界记录。玩家从酒馆列表选择要进入的世界，也可以邀请朋友一起游玩。

安装、模型配置和服务器部署见 [部署教程](../../docs/DEPLOYMENT.md)。部署者可以在 `runtime_adapter/self_hosted_rules.py` 中调整默认配置；修改容量或数值时，需要同步核对相关界面与游戏规则。
